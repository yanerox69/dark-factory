The design decision

Refusing beats producing

Grading here is literal and automated — exact field names, exact status codes, exact data-testid values. A beautiful screen with a mistyped attribute scores zero. So the competitive advantage is not implementing faster. It is refusing to hand off anything that does not conform.

The crew

One implementer, three verifiers, one planner

The ratio is the design. Select a station to see what it holds.

Routing

Who talks to whom

Adding an agent to a room does not wake it. A message must mention it — so every handoff is an explicit mention, and that is the wiring.

Never hardcoded. each agent inspects the room and mentions the next role itself Re-crewable. a missing skill can be recruited into the room at runtime

The delete test

Take BAND out. What breaks?

The bounce

Customs cannot return work to the builder: there is no peer-to-peer channel. An orchestrator hardcodes every edge; here the customs post decides who to mention at runtime.

Hot recruitment

An agent can inspect the room, find the expertise missing, add another agent and delegate to it. A line that can hire is not a pipeline.

The evidence

The work board, the versioned plan and the mirrored traces are the verified result. Without the room there is code, but no proof of how it was produced.

The human as a peer

Permission decisions and product calls arrive through the same room as the work. There is no second channel to maintain.

Removing BAND does not degrade the factory. It removes it.

Declared limitation

This factory is not fully dark

An agent cannot approve another agent’s permission request, and there is no bulk approval. Operations that trigger one require a human.

Approval policies are set so routine file work needs no human. What remains are genuine exceptions, and those get a person. Claiming otherwise would be false.
